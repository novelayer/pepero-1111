# 현지에게 도착한 허찌의 달콤한 선물 🎁 (v5)

2026년 11월 11일 22시 빼빼로데이 서프라이즈 웹페이지다. 모몽가가 빼빼로 4종을 직접 만들어 포장하고, 현관 문고리까지 배달한다. 이야기는 약 48초다 (편지를 읽는 시간은 빼고).

**현지가 참여하는 곳은 두 군데다.**

1. **수령 서명**
   - 손가락, 펜, 마우스로 서명하고 "선물 열어보기"를 누르면 시작한다. "서명 없이 받기"도 있다.
   - 이 서명이 마지막 영수증에 다시 나온다.
2. **하트 뿌리기**
   - 딸기 빼빼로에 하트를 뿌릴 때 화면을 톡톡 누르면 하트가 떨어지고, 일부가 빼빼로에 붙는다.
   - 3초 동안 누르지 않으면 하트 하나만 살짝 얹히고 자동으로 넘어간다.

**만드는 과정**

모몽가 손에는 작은 흰 손 레이어가 붙어 있다. 원본 그림은 그대로 두고, 도구를 쥔 자리에만 얹은 것이다. 주걱, 과자, 토핑통은 이 손을 따라 움직인다.

1. **초콜릿 녹이기**: 젓는 동안 초콜릿 한 방울이 튀어서 모몽가가 깜짝 놀란다.
2. **오리지널**: 과자를 담그고, 잠깐 멈췄다가, 천천히 들어 올린다. 초콜릿이 실처럼 늘어졌다 한 방울 떨어지고 파문이 생긴다. 모몽가가 바라본 뒤 유리컵에 거꾸로 세운다.
3. **아몬드**: 코팅한 뒤 토핑통을 세 번 흔든다. 흔들 때마다 조각이 떨어져 표면에 붙는다.
4. **딸기**: 딸기 볼로 바꿔서 분홍 코팅을 입히고, 현지가 하트를 뿌린다.
5. **누드**: 단면을 확대해서 과자 속이 초콜릿으로 채워지는 모습을 보여 준다.
6. **굳히기와 진열**: 굳히기, 모몽가의 멍한 1초, 나무 트레이 진열(ORIGINAL·ALMOND·STRAWBERRY·NUDE), 품질 검사 "완벽!"이 이어진다.
7. **포장**: 하나씩 투명 포장하고 색이 다른 종이 밴드를 두른다. 쇼핑백 입구 뒤쪽으로 넣고, 리본이 흔들리면 이름표가 나온다.

**하트 하나가 이어지는 이야기**

하트는 새로 쏟아지지 않는다. 같은 모양·같은 색의 작은 하트 하나가 이렇게 이어진다.

1. 서명 완료 → 카드가 접히면 작은 하트가 나와 가방 리본으로 날아간다 → 리본이 흔들리고 따뜻한 빛
2. 딸기 빼빼로 토핑
3. 가방 이름표 "For. 현지"
4. 편지 봉투 봉인

**배송과 엔딩 (대답을 요구하지 않음)**

1. 모몽가가 가방을 들고 통통 뛰어 현관으로 간다.
2. 손잡이가 문고리에 걸리고, 가방과 리본이 한 박자 늦게 흔들린다.
3. 모몽가가 돌아서서 가려다 한 번 뒤돌아본다.
4. 모몽가가 화면 가장자리로 물러난다.
5. 띵동이 울린다.
6. 2초 동안 정적이 흐른다. 자막, 말풍선, 버튼, 진행 막대 없이 현관 불빛과 가방만 남는다.
7. 현관 불빛이 따뜻해지며 "현지야, 나 계속 좋아해주라 ♡"가 한 글자씩 나타나 2초쯤 머문다. 버튼이나 선택지는 없다.
8. 크림색 봉투가 아래에서 올라온다. 봉투에는 "현지에게", 소인 "11.11 / 22:00", 하트 봉인이 있다.
9. **현지가 "편지 열어보기"를 직접 누른다.** 편지는 자동으로 열리지 않고, 읽는 동안 자동으로 넘어가지도 않는다.
10. 편지 아래 "배송 확인하기"를 누르면 영수증이 나온다. 영수증에는 주문번호 HJ-1111, 서명(또는 "현지 수령 확인"), 배송 완료 도장이 있다.
11. 마지막 화면: "이제 진짜 문 열어 봐 ♡" / "현지에게 도착한 허찌의 선물". 이 화면은 자동으로 끝나지 않는다.

마지막 화면의 "작은 보너스가 숨어 있어요"를 누르면 메뉴가 펼쳐진다.

- 빼빼로 4종 구경하기 (맛별 한마디)
- 모몽가 칭찬하기 (10번째에 특별 반응)
- 편지 다시 보기, 영수증 보기
- 처음부터 다시 보기

편지나 영수증을 읽는 동안에는 배경 반복 움직임이 멈추고 현관이 살짝 어두워진다.

**화면과 기기 지원**

- 아이폰, 아이패드, PC에서 같은 장면이 보인다.
- 키보드만으로 끝까지 볼 수 있다.
- 스크린리더가 진행 상황을 읽어 준다.
- 기기에서 '동작 줄이기'를 켜 두면 움직임이 줄어든다.
- 효과음은 기본으로 꺼져 있다. 오른쪽 위 버튼으로 켤 수 있다.

## 1. 내 컴퓨터에서 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/ 생성
npm run preview    # 빌드 결과 확인
```

## 2. GitHub Pages로 배포 (링크 만들기)

1. GitHub에서 새 저장소를 만든다.
   - 이름은 `pepero-1111`처럼 중립적으로 짓는다. 카톡 미리보기에 주소가 보이기 때문이다.
   - 무료 GitHub Pages는 **Public 저장소**에서만 된다.
2. 이 폴더 전체를 올린다. 숨김 폴더 `.github`도 꼭 함께 올려야 한다.
   ```bash
   git init && git add . && git commit -m "pepero 1111"
   git branch -M main
   git remote add origin https://github.com/<아이디>/pepero-1111.git
   git push -u origin main
   ```
   웹에서 드래그로 올렸다면, 올린 뒤 저장소에 `.github/workflows/deploy.yml`이 있는지 확인한다.
3. 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 바꾼다.
4. **Actions** 탭에서 `Deploy to GitHub Pages`가 초록색으로 끝나면 주소가 생긴다: `https://<아이디>.github.io/pepero-1111/`

## 3. 카톡 미리보기

- 카톡 '나와의 채팅'에 링크를 보내서 확인한다.
- 실물 쇼핑백이 가운데, "To. 현지" 이름표가 함께 보여야 한다. 고백 문구나 편지 내용은 미리보기에 나오지 않는다. 미리보기 이미지는 `public/og.jpg`이다.
- 예전 미리보기가 계속 보이면 카카오 개발자 사이트의 공유 디버거에서 캐시를 초기화한다.

## 4. 문구·편지 바꾸기

전부 `src/content.js` 한 파일에서 바꾼다.

| 바꾸고 싶은 것 | 위치 |
| --- | --- |
| 오프닝 제목·부제 | `intro` |
| 서명 화면 문구 | `sign` |
| 장면 자막, 모몽가 대사 | `captions`, `lines` |
| 하트 뿌리기 문구 | `topping` |
| 고백 문구 | `love` |
| 편지 봉투 (받는 사람, 소인, 버튼) | `envelope` |
| 맛별 한마디 | `flavors` |
| **손편지 내용** | `letter.title`, `letter.greeting`(첫 인사), `letter.paragraphs`(문단 → 줄 배열), `letter.closing`, `letter.date`, `letter.sign`, `letter.next`(편지 아래 버튼) |
| 영수증 항목·배송 일시 | `receipt.rows` |
| 엔딩 문구, 칭찬 대사 | `ending` |
| 빼빼로 4종 색·코팅·종이 밴드 색 | `src/props.jsx`의 `PEPEROS` |

문구를 바꾼 뒤에는 아래 명령을 한 번 실행한다. 새로 쓴 글자가 폰트 파일에 들어간다. 실행하지 않아도 화면이 깨지지는 않고, 그 글자만 기본 폰트로 보인다.

```bash
pip install fonttools brotli
python3 scripts/subset-fonts.py
```

폰트 세 가지와 쓰이는 곳:

- Pretendard: 본문, **편지 본문** (읽기 편하게 손글씨가 아닌 본문 서체 16px, 줄 간격 1.85)
- Jua: 제목
- Gaegu: 고백 문구, 편지 제목·서명, 봉투의 "현지에게"

## 5. 이미지

- **모몽가**: 보내 준 사진만 자르거나 배경을 지워서 쓴다. 새로 그리거나 생성하지 않았다.
  - `scripts/prepare-assets.py`: 표정 배지, 폴라로이드
  - `scripts/prepare-cutouts.py`: 셰프 스티커
- **칭찬 볼터치**: 원본 그림 위에 반투명 분홍 층을 얹은 것이다. 얼굴을 새로 그린 것이 아니다.
- **실물 쇼핑백**: 보내 준 정면 사진을 잘라 밝기만 조정했다 (`public/bag/bag-front.webp`). 가방 손잡이는 그림이다.
- **배경**: 공방, 현관, 오프닝 식탁 모두 `src/bg.jsx`의 SVG 그림이다.

## 7. 아이폰(사파리)·파이어폭스 엔진으로 자동 확인

저장소의 **Actions → Check on Safari·Chrome·Firefox engines → Run workflow**를 누른다. 3개 엔진 × 7개 화면 × 10개 장면을 찍는다. 화면은 아이폰 SE·15·Max, 가로 폰, 아이패드 세로·가로, PC다.

- 결과 사진은 실행 화면 아래 `browser-shots`에서 받는다.
- 빨간 X가 뜨면 오류가 있다는 뜻이다.
- 이 확인은 실제 기기를 대신하지 못한다. 카톡 인앱 브라우저와 실제 아이폰·아이패드에서 직접 한 번씩 끝까지 해 본다 (서명, 하트 뿌리기, 편지, 영수증까지).

## 9. 알아둘 것

- **개인 선물 페이지다.** 검색에 노출되지 않게 막아 두었다 (`noindex`, `robots.txt`).
- **공개 저장소라서 편지 문구와 이미지가 GitHub에서 보일 수 있다.** 이벤트가 끝나면 저장소를 지우거나 Private로 바꾸는 것을 권한다.
- **서명**은 현지 폰의 메모리에서만 쓰인다. 서버로 보내지 않고, 브라우저 저장소에도 남기지 않는다. 새로고침하면 사라진다.
- **진동**은 띵동 순간에 안드로이드에서만 된다. 아이폰은 웹 진동을 지원하지 않는다.
- **모몽가 꼬리**는 원본 그림의 일부라서 따로 움직이지 않는다. 몸 전체가 움직일 때 함께 움직인다.
- **효과음**은 기본으로 꺼져 있고, 켜도 작고 부드럽게 나온다 (휘휘, 퐁당, 솔솔, 사각사각, 띵동). 무음 모드에서는 안 들릴 수 있다. 소리가 없어도 이야기는 그대로 이해된다.
- **폰트 라이선스**: Pretendard, Jua, Gaegu 모두 SIL OFL 1.1이다. 원본은 `fontsrc/`에 있다.
